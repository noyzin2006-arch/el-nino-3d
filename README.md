# 厄尔尼诺，从海面到全球｜3D 交互讲解

一个中文单页教育演示：用可操纵的 Three.js 三维海洋剖面，讲解厄尔尼诺（El Niño）的形成机制与全球影响。

## 运行

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 7100 --strictPort
```

浏览器打开终端里显示的地址（默认 `http://localhost:7100/`）。CLI 的 `--host` / `--port` 参数原样透传给 Vite，不写死在脚本里。

其它命令：

```bash
npm test     # node:test 纯逻辑回归（状态机 / 物理参数 / 文案）
npm run build
npm run preview
```

## 内容结构

三幕递进叙事，步骤切换驱动 3D 场景连续插值：

1. **正常年份**——信风把表层暖水吹向西太平洋；东部温跃层浅、上升流活跃；雨带在西部。
2. **暖水东移**——信风减弱，暖水向中东太平洋扩展，东部温跃层加深、上升流受抑制，雨带东移。
3. **全球影响**——在四张地域卡中说明秘鲁/厄瓜多尔洪涝风险、秘鲁近海渔业、印尼/澳大利亚干旱风险、中国冬季偏暖概率，并强调“典型倾向，并非每次必然”。

## 技术与设计

- Vite + 原生 ES Modules + npm `three`（无 CDN、无框架、无外部字体/图片）。
- 场景组成：半透明海盆剖体、顶点色海面（相对暖冷示意）、温跃层 3D 曲面与前缘黄线、信风箭头、沃克环流点线、东部上升流虚线、雨带与影响导向弧。所有资源创建一次，动画只更新 buffer/透明度。
- 可访问性：核心路径全键盘可达、aria-live 状态播报、canvas 有等效文字说明（figcaption + aria-label）、focus-visible 2px 焦点环、`prefers-reduced-motion` 下停流动画并即时切态。
- 降级：WebGL2 不可用时自动切换纯文字学习模式；WebGL 上下文丢失后可点击“重试三维绘制”（换用全新画布重建，最多两次）。

## 科学边界

本页是**概念示意**：箭头速度、温跃层高度、海表颜色均不按实际比例，也不展示任何实时监测数据或预测。影响表述均为概率倾向。来源见页脚（NOAA / NASA 等）。

## 故障排查

- 端口被占用：`--strictPort` 会报错退出，换一个 `--port` 即可。
- 画面提示“三维绘制被中断”：点击“重试三维绘制”；两次失败后页面保持纯文字模式，三幕内容仍可完整学习。
