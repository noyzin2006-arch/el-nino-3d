# 简报：3D 网页展示厄尔尼诺的形成与影响

## 任务
做一个 3D 模型的教育型网页（中文界面），用可交互的三维场景讲解厄尔尼诺（El Niño）现象是怎么形成的、带来什么影响。用户原话：「做一个3D模型网页展示，讲解厄尔尼诺现象是怎么形成的，带来什么影响」。

## 验收
1. `npm install && npm run dev` 后页面可访问（开发服务器需把 CLI 传入的 host/port 参数透传给底层框架）；浏览器打开无白屏、控制台无报错。
2. 页面包含一个可交互的 3D 场景（OrbitControls 或等价交互）：展示赤道太平洋、信风、沃克环流、温跃层（thermocline）、海表温度（SST）异常。3D 内容必须使用 three.js（npm 安装），不许用静态截图或视频冒充 3D。
3. 有明确的「形成机制」叙事：至少覆盖 正常年份（信风驱动、东部冷水上涌）→ 厄尔尼诺年（信风减弱、温跃层变平、暖水东移）→ 影响（全球气候异常：秘鲁渔场减产/洪水、印尼澳大利亚干旱、中国暖冬等）三段，且每段与 3D 场景状态联动（时间轴或步骤切换时 3D 状态变化）。
4. 中文文案科学准确、无臆造数据；响应式：1440px 与 390px 宽度下均可读可用。
5. 最终交付形态：本机项目根目录 `npm run dev` 即可预览；不得依赖外部付费 API 或真机。

## 背景与约束
- 本机：macOS arm64；Node v24.21.0；npm 11.12.1；无 TTY（不能跑交互式脚手架向导）；无付费 API key；无真机。
- 交付通道约束：最终成品是 Kimi Work 里的本地网页项目，交付时项目根目录的 `npm run dev` 必须能起开发服务器，且把命令行传入的 host/port 参数转发给底层框架（Vite 天然支持）。预览地址以 `http://localhost:7100/` 为逻辑端口（宿主会自行重映射），不许用 `file://` 或指向构建产物的 URL。
- 网络：npm 安装公开包可用；three.js 走 npm（`npm i three`），不要 CDN 外链（离线可复现）。
- 3D 实现只用 three.js + 原生 WebGL；不引入 React Three Fiber 等封装（减少依赖面，零提问前提下避免版本坑）。构建用 Vite。
- 科学事实基线（供核对，规划案不必重述）：厄尔尼诺=赤道中东太平洋海表温度持续异常偏暖；成因是沃克环流减弱/信风减弱，西部暖水向东回流，东部温跃层加深、上升流减弱；典型影响包括秘鲁沿岸渔业减产、南美西岸暴雨洪涝、印尼/澳大利亚干旱、印度季风减弱、中国东部暖冬概率上升。
- 本轮明确不做：后端服务、用户账号、多语言、移动端原生 App、真实气象数据集接入、音效。

## 本轮范围
做：单页应用（Vite + three.js），信息架构（标题/导览/3D 画布/步骤叙事/影响清单），3D 场景（海洋平面、大气层示意、风场箭头、温跃层曲面、SST 色带），时间轴步骤切换驱动 3D 状态插值动画，中文排版与响应式，加载与错误状态。
不做：登录/后端、真实数据 API、音频、PWA。
